How to Edit This Repo

This site is built with plain HTML and CSS — no special tools required. All files live in the PE-Repository- folder.

Step 1 — Open the file in VS Code

Open VS Code, then open the folder PE-Repository-. The main file you'll edit is index.html.

Screenshot: VS Code with index.html open

Step 2 — Adding a new button

Find the correct panel and sub-section in index.html. Copy an existing button line and update the text and link:

<a href="YOUR_LINK" class="link-btn" target="_blank" rel="noopener">Button Label</a>

Use href="#" as a placeholder if the link isn't ready yet.

Screenshot: button line in code vs. what it looks like on the site

Step 3 — Adding a new sub-section

Inside a building accordion <div class="building-body">, add a new collapsible group:

<details class="sub-section" open>
  <summary class="sub-heading">Section Title<span class="sub-chevron">&#9660;</span></summary>
  <a href="#" class="link-btn">Button Label</a>
</details>
Screenshot: sub-section in code vs. what it looks like on the site

Step 4 — Pushing changes to GitHub

After saving your edits, open Terminal and run:

cd ~/PE-Repository-
git add index.html
git commit -m "brief description of your change"
git push origin main

Changes will appear on the live site within a few seconds.

Screenshot: Terminal showing a successful git push

Step 5 — Confirm it's live

Go to the GitHub repo page and confirm your commit appears at the top of the commit history.

Screenshot: GitHub repo showing the latest commit
